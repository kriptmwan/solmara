Solmara is an open-world crime game set in a sun-soaked coastal city of its own: explore on foot and by car, steal and drive vehicles, dodge traffic and pedestrians, outrun the Solmara PD as your wanted level rises, and run missions for the people who own the streets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard and mouse. No network needed: the game is plain static files under `game/`.
